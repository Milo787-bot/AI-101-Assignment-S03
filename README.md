# บทที่ 3: Assignment (การบ้าน)

ส่วนหนึ่งของ [week_03.md](../week_03.md)

## เป้าหมาย

ฝึกใช้ framework แบบ spec-driven/agentic (GSD หรือ GitHub Spec Kit) กับงานจริงของตัวเอง และฝึกเปรียบเทียบว่า framework ต่างจาก prompt ธรรมดาตรงไหน

## รายละเอียดงาน

เลือก feature หรือ task เล็กๆ จากงานจริงของตัวเอง (หรือโปรเจกต์ส่วนตัว) แล้ววางแผน/ลงมือทำด้วย framework อย่างน้อย 1 ตัว (GSD **หรือ** GitHub Spec Kit) ให้ครบ workflow ของ framework นั้น จากนั้นเขียน reflection เทียบกับการสั่งงาน AI แบบ prompt ธรรมดา

> **หมายเหตุ:** framework ตัวที่ 3 ของบทนี้ยังรอยืนยันชื่อ — ถ้าผู้สอนเติมข้อมูลก่อนถึงกำหนดส่งการบ้าน ผู้เรียนสามารถเลือกใช้ framework ตัวที่ 3 แทน GSD/Spec Kit ได้เช่นกัน

## ขั้นตอนที่ต้องทำ

1. เลือก feature/task เล็กๆ ที่ทำได้จบภายในเวลาที่กำหนด (ประเมินเวลาก่อนเริ่ม)
2. เลือก framework 1 ตัว: **GSD** (research → plan → discuss → execute → verify) หรือ **GitHub Spec Kit** (specify → plan → tasks → implement)
3. ทำตาม workflow ของ framework นั้นให้ครบทุกขั้นตอน จนได้ผลลัพธ์ (โค้ด/ไฟล์ที่ framework สร้างให้ เช่น spec.md, plan.md, tasks.md)
4. ลองสั่งงาน AI ด้วย prompt ธรรมดา (ไม่ผ่าน framework) กับ feature/task เดียวกันหรือคล้ายกัน เพื่อเทียบผล
5. เขียน reflection ~150–200 คำ: framework ที่เลือกช่วยตรงไหนที่ prompt ธรรมดาช่วยไม่ได้ และมีข้อเสีย/overhead อะไรบ้าง

## สิ่งที่ต้องส่ง

- ไฟล์ผลลัพธ์จาก framework ที่เลือก (เช่น spec.md/plan.md/tasks.md จาก Spec Kit หรือ artifact จาก GSD)
- บันทึกเปรียบเทียบกับการสั่งงานแบบ prompt ธรรมดา
- Reflection ~150–200 คำ

## เกณฑ์การให้คะแนน

| เกณฑ์ | น้ำหนัก |
| --- | --- |
| ใช้ framework ที่เลือกจนครบ workflow จริง | 50% |
| มีการเปรียบเทียบกับ prompt ธรรมดาอย่างเป็นรูปธรรม | 25% |
| Reflection เชื่อมโยงข้อดี/ข้อเสียของ framework ได้ชัดเจน | 25% |
